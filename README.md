# 星芽儿歌

一个面向 84 首英文启蒙儿歌的本地 PWA 播放器，按 14 个主题分类。

## 已实现

- 84 首英文启蒙儿歌，14 个主题分类

- 单曲循环、顺序播放、随机播放
- 上一曲、下一曲
- 手机锁屏与后台播放（使用原生 `<audio>` 与 Media Session API）
- 每首歌累计播放次数
- 当日所有儿歌累计播放时长，零点自动开始新一天
- 播放记录保存在浏览器本机，退出后仍然保留
- 可安装到手机或电脑桌面
- 响应式布局，适配手机、平板和桌面

## 打开方式

双击 `启动儿歌播放器.command`。它会启动本地服务器并打开浏览器。

也可以在本目录手动运行：

```bash
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/?v=84>。

在线版：<https://jingjie0209.github.io/xingya-kids-songs/>

GitHub Pages 使用 `docs/` 中的轻量页面，音频通过 GitHub 仓库的 jsDelivr CDN 加载。

## 安装说明

- iPhone / iPad：使用 Safari 打开，点「分享」→「添加到主屏幕」。
- Android：使用 Chrome 打开，点菜单 →「安装应用」。
- Mac / Windows：Chrome 或 Edge 地址栏右侧点安装图标。

浏览器要求安装页面运行在 `localhost` 或 HTTPS 环境。若要安装到手机并在家庭网络使用，建议部署到 GitHub Pages、Cloudflare Pages 或任意 HTTPS 静态托管。84 首音频共约 232MB，播放过的歌曲会由浏览器增量缓存。

## 后台播放说明

播放开始后，切到桌面、锁屏或打开其他应用，音频会继续播放；锁屏界面也支持播放、暂停和切歌。不要从系统后台彻底划掉浏览器/PWA 进程，否则任何网页播放器都会停止。

统计只保存在当前设备和当前浏览器，不会上传到服务器。
